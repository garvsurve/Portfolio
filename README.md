# ⚡ Neo-Brutalist Developer Portfolio

A bold, high-contrast professional portfolio built with a **Neo-Brutalist** design aesthetic. This project showcases my journey as a Full-Stack Engineer specializing in **Java Spring Boot** and Cloud Foundations.

## 🚀 Overview

This portfolio deviates from traditional minimalist designs, embracing the raw and bold characteristics of Neo-Brutalism:
- **Hard Borders & Shadows**: Defined with 4px to 8px black strokes.
- **Vibrant Palettes**: Utilizing high-contrast colors like Neo-Yellow, Neo-Pink, and Neo-Blue.
- **Asymmetric Layouts**: Intentional rotations and offset elements for a dynamic feel.
- **Typography Focused**: Using bold, uppercase Space Grotesk for maximum impact.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: CSS Keyframes + Tailwind Transitions

## ✨ Key Features

- **Dynamic Hero Section**: Interactive elements with a strong call-to-action.
- **Achievement Stats**: Live highlighting GFG University Rank and LeetCode solve counts.
- **Project Gallery**: Neo-card layouts with detailed tech-stack tags and GitHub integration.
- **Skill Toolbox**: Categorized technical arsenal with hover effects.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/garvsurve/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env` file in the root directory:
   ```env
   VITE_EMAILJS_SERVICE_ID=your_id
   VITE_EMAILJS_TEMPLATE_ID=your_id
   VITE_EMAILJS_PUBLIC_KEY=your_key
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```
